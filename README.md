# 🤖 AI Daily Planner Agent using n8n

## 📌 Overview

An AI-powered Daily Planner built using n8n, OpenAI, and Google Sheets.

The AI Agent can read tasks from Google Sheets and answer user questions in natural language.

## 🚀 Features

- Read tasks from Google Sheets
- Answer questions using AI
- Filter pending tasks
- Show high-priority tasks
- Display learning/work tasks
- Natural language interaction

## 🛠️ Tech Stack

- n8n
- OpenAI GPT
- Google Sheets
- AI Agent
- Chat Trigger

## 📂 Workflow

Chat Trigger
↓
AI Agent
├── OpenAI Chat Model
└── Google Sheets Tool

## Example Questions

- What are my pending tasks?
- Show high-priority tasks.
- What learning tasks do I have?
- What tasks are completed?
